# Contributing

Thank you for contributing to this repository.

## Maintainer

- Repository owner and final reviewer: **@tptm**

## Contribution Rules

1. **Pull Requests only**  
    - All changes must be submitted through a Pull Request (PR).  
    - Direct pushes to any protected or main branch are not allowed.

2. **Open an issue first (recommended)**  
    - For significant changes, open an issue to discuss scope before creating a PR.

3. **Keep PRs focused**  
    - Submit small, single-purpose PRs with clear descriptions.

4. **PR requirements**  
    - Include a summary of changes and motivation.
    - Reference related issues when applicable.
    - Ensure checks/tests pass before requesting review.

5. **Review and merge policy**  
    - Only **@tptm** approves and merges PRs.

## Code of Conduct

- Be respectful and constructive in all discussions.
- Contributions may be closed if they do not follow these rules.
